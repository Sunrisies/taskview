# TaskView 下载版安装说明

下载版已经编译完成，不需要 Xcode、Python、拉取源码或导入开发证书。

## 系统要求

- macOS 14 或更新版本。
- 下载包名称含 `arm64` 时仅适用于 Apple Silicon（M 系列芯片）。
- 当前提供的 Beta 包未经过 Apple 公证，首次打开可能出现无法验证开发者的提示。

## 安装

1. 从项目 GitHub Releases 页面下载 TaskView 的 ZIP 或 DMG。
2. ZIP 解压后，将 `TaskView.app` 拖入“应用程序”；DMG 打开后，将应用拖到 `Applications` 快捷方式。
3. 从“应用程序”打开 TaskView。应用在顶部菜单栏显示叠放窗口图标，不显示 Dock 图标。
4. 如果 Beta 版被系统拦截，请先确认下载来源；尝试打开后，到“系统设置 → 隐私与安全性”查看“仍要打开”。具体操作见 [Apple 安装说明](https://support.apple.com/zh-cn/102445)。若系统认定文件损坏，不应直接当成普通开发者提示忽略，可先重新下载并核对校验值。

## 首次权限

TaskView 需要两项权限，都授予安装在“应用程序”中的这一份应用：

| 权限 | 用途 |
| --- | --- |
| 屏幕录制／屏幕与系统音频录制 | 读取其他应用的窗口信息并生成缩略图；当前应用不录制音频。 |
| 辅助功能 | 聚焦、请求关闭指定窗口。 |

授权后从菜单栏退出 TaskView，再从“应用程序”重新打开。设置页的“重新检查权限”可以验证窗口读取。

不要安装发布者的证书或私钥，也不需要关闭 macOS 的全局安全保护。

## 使用

- 默认 `⌥Tab` 打开任务视图，方向键选择，回车打开。
- 输入标题或应用名搜索；Esc 先清空搜索，再按一次关闭。
- 顶部可切换显示器范围、应用分组。
- 卡片右上角 × 请求关闭窗口，目标应用可能显示保存确认。
- 菜单栏 →“设置…”可修改快捷键、自启、清晰度等。
- 建议放入“应用程序”后再开启自启，避免路径变化。

## 升级和卸载

升级前退出旧实例，用新版本替换“应用程序”中的 `TaskView.app`，然后重开。签名身份变化时可能需要重新授权；保持同一个应用路径。不要同时运行下载目录和“应用程序”中的两份副本。

卸载前在设置中关闭自启，从菜单栏退出，再移除应用。若需要清除偏好和诊断数据，可在终端执行下面两条命令；它们不会删除你的其他应用窗口或文档：

```bash
defaults delete com.zhuzhongqian.taskview
rm -rf "$HOME/Library/Application Support/TaskView"
```

## 校验下载文件

发布附件包含 `SHA256SUMS.txt`。将它和对应 ZIP／DMG 下载到同一个目录，再在该目录运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

若只下载 ZIP，校验结果中缺少 DMG 的提示表示该文件未下载；已下载的 ZIP 应显示 `OK`。校验值确认文件是否完整，不能代替开发者身份验证和 Apple 公证。
