# TaskView 隐私说明

TaskView 当前是本地窗口切换工具，没有实现联网、遥测、账户登录或自动更新功能，也不上传窗口图像。

- 窗口标题、应用名、位置尺寸用于显示、搜索、筛选和目标匹配。
- 窗口缩略图保存在内存中，用于任务视图预览；离开可见区域或关闭覆盖层时移除应用持有的图片引用，不作为图片文件保存到磁盘。
- 快捷键、显示范围、分组和清晰度等偏好通过 macOS UserDefaults 保存。自启由系统登录项服务管理。
- 发布版默认不写文件诊断日志。用户主动以 `--debug-log` 开启后，日志可能包含应用路径、进程 ID、窗口数量、屏幕坐标和错误信息，不记录搜索框输入内容或保存截图。
- 诊断日志位于 `~/Library/Application Support/TaskView/`，当前文件和单份备份均限制大小。
- 关闭窗口使用目标应用的辅助功能关闭按钮动作，保存确认和取消由目标应用处理。

如向开发者提供日志排查问题，请先检查是否包含不希望公开的本机路径等信息。系统权限可随时在“隐私与安全性”中撤销。
